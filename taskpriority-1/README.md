## **Project Description**
The **Task Priority Manager** is a decentralized application built on the Flare Coston2 testnet that allows users to create, store, and manage prioritized tasks entirely on-chain.

Each task includes:
- A description  
- A priority level (Low, Medium, High)  
- A completion status  

Tasks are immutable once stored, ensuring transparency and consistency across all users.

---

## **Features**
### ✅ **1. Add Tasks On-Chain**
Users can create new tasks by providing:
- A task description  
- A priority level (0 = Low, 1 = Medium, 2 = High)

### ✅ **2. Complete Tasks**
Tasks can be marked as completed using their on-chain unique ID.

### ✅ **3. View All Tasks**
All tasks stored in the contract are displayed including:
- ID  
- Description  
- Priority  
- Completion status  

### ✅ **4. Trustless & Transparent**
All task data is permanently stored on-chain and can be verified through blockchain explorers.

### ✅ **5. Wallet Gating + Transaction Status**
- Requires wallet connection  
- Shows pending/loading/confirmed states  
- Displays transaction hash and errors

## **How This Project Solves Real Problems**
Task management tools today rely on centralized databases that can fail, lose data, or restrict access.  
The **Task Priority Manager** solves these problems by leveraging Web3 benefits:

### 🌐 **Decentralization**
Your tasks live on the blockchain, not on a server.

### 🔒 **Security**
No one can modify or delete your tasks except through valid smart contract calls.

### 🔍 **Transparency**
Anyone can verify tasks, priorities, and completion status directly on the Flare explorer.

### 💼 **Use Cases**
- Team task management  
- Transparent project tracking  
- Immutable milestone logging  
- Blockchain-based to-do lists  
- Public accountability tracking
